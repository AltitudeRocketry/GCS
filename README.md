**Ground Control Station**

*This app is property of Altitude Rocketry*

Download the latest release from the release section. It will ask for permission to make changes to device and you should click yes.
The app will take a bit to open.

Once its open there are 3 main windows: Data Analyzer, Test Stand and Notifications

**Data Analyzer:**
The purpose of this page is to download the flight logs from the flight computer and analyze it.
To connect the flight computer, connect it via usb to your computer and click connecct board. It will open a pop up screen where you will need to select the COM port and the Baud Rate for the flight computer. 
After that, you need to click on the file save location button. This will open a window where you need to save a file containing all the data from the fight computer. We recommend creating a folder named Flights where you log all of your flight data

After the file has been created, click connect board. 

This completes all the process for connecting the board to the computer. To read from the flight computer click on flash dump. This will dump all the flight log into the saved file

After that, you need to select the variables that you want to graph and click update. If you want to add more variables to the graph select the new variable and click update.  If you want to reset the graph, click reset.


**Test Stand:**

The purpose of this page is to have an easy way of viewing in real time the data from a motor test. To perform this you need to have our product **_Test Stand Product_**. 

To connect the test stand to the app, go to your networks and select the wifi network from the test stand then, click link telemetry. If the connection is successfull at the top right it will appear connected.
After that you will need to calibrate the device click calibrate and follow the instructions, If you know already the calibration value you can click set and set it manually.

Then, click test to ensure the SD card and the load sensor from the  **_Test Stand Product_** are working correctly. If at the top left you see SD Card and Load cell with a 1 its good to go. 

Click memasure to start measuring and reading the graphs and then ignite to ignite the pyro.

the stop button will stop all incoming data

**Notifications**

Here you will have access to any updates on the app or test stand or flight computer code.
